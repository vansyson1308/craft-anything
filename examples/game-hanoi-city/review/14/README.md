# Draft: second thief character study

This is an early review candidate, not a game-ready replacement. Nothing in
this folder is registered in the game's asset manifest. The clothed stocky
character uses a transferred version of the existing thief rig, an unbranded
cap and a simple face covering. The close and medium LODs preserve more jacket
detail; the automatically reduced distant LOD has visible gaps in the jacket
and needs manual repair. The cap, mask, anatomy, silhouette and clothing also
need an artist's refinement.

| Study | Triangles | Materials | Embedded images | glTF Validator |
| --- | ---: | ---: | --- | --- |
| `stocky_atlas.glb` | 24,383 | 4 | 4 × 1024² | 0 errors, 0 warnings |
| `stocky_lod1.glb` | 7,843 | 4 | 4 × 512² | 0 errors, 0 warnings |
| `stocky_lod2.glb` | 1,846 | 4 | 4 × 256² | 0 errors, 0 warnings |

The files have the same 65 joint names and order as `assets/hq/people/trom_01.glb`,
at most four influences per vertex, normalized weights and maximum inverse-bind
matrix differences below 0.000005. This is a compatibility check, not proof
that the rig deforms correctly throughout all animations. `action_sheet.png`
shows one sampled frame each from the existing Idle, Sprint, Crouch, Punch,
Roll and Death actions; it is not a full animation or collision test. The
`stocky_tpose.png` and `stocky_lod*.png` images show the bind-pose studies.

Outstanding before game use: repair the distant LOD's openings and inspect
all LOD transitions; improve the character design, mask, cap and hair; clean
skin weights and inspect every animation for penetration and foot contact;
measure UV utilization, seams and texel density; produce and inspect the
required model-specific high-to-low normal/AO bake; integrate only after
review, then test the actual game and lighting. The existing texture maps are
source maps and a packed atlas, not evidence of a completed bake.

## Sources and reproduction

The starting human, clothes, skin, hair, eyes and eyebrows come from the
MakeHuman system asset pack, distributed as CC0:
<https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip>.
The relevant asset headers credit MakeHuman/Data Collection AB, Joel Palmius
and Jonas Hauquier. MPFB was used as a build dependency from
<https://github.com/makehumancommunity/mpfb2>, commit
`6ff1eb358f6c1959ced77e79e6dd2406d9a71f49` (its code has its own license;
it is not copied into this repository). The base game's rig is taken from the
existing `trom_01.glb`. The cap and covering are generated by our script.

With Blender 4.5.15, a matching Python `bpy` environment, NumPy and Pillow,
check out MPFB at that commit and extract the CC0 system asset pack into
`<userdir>/data`. Run from `examples/game-hanoi-city`:

```text
blender --background --factory-startup --python-exit-code 1 --python art-src/character/build_stocky_study.py -- --mpfb-source <mpfb-checkout> --userdir <userdir>
python art-src/character/pose_stocky_study.py <userdir>
python art-src/character/transfer_stocky_study.py <userdir> assets/hq/people/trom_01.glb
python art-src/character/atlas_stocky_study.py <userdir>/stocky_transferred.glb <userdir>/stocky_atlas.glb
python art-src/character/make_stocky_lod.py <userdir>/stocky_atlas.glb <userdir>/stocky_lod1.glb
python art-src/character/make_stocky_lod.py <userdir>/stocky_atlas.glb <userdir>/stocky_lod2.glb --lod2
python art-src/character/check_stocky_study.py assets/hq/people/trom_01.glb <userdir>/stocky_atlas.glb
python art-src/character/render_stocky_actions.py <userdir> assets/anim.glb
```

Run the checker on each LOD and validate each GLB separately. Regenerated
binary hashes need not match because Blender's export is not byte-stable.
